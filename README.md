# MétéoInstant
Application météo : géolocalisation, recherche de ville, prévisions 7 jours, graphiques Chart.js (7 jours / 48 h).
Données : API REST Open-Meteo (gratuite, sans clé).

## Lancer
Placer le dossier dans `C:\wamp64\www\MeteoInstant` puis ouvrir http://localhost/MeteoInstant/
(La géolocalisation exige `localhost` ou HTTPS ; un double-clic sur index.html fonctionne mais sans géolocalisation selon le navigateur.)
